Projeto de Banco de Dados – Money Makers BB
Este projeto foi desenvolvido como atividade acadêmica, utilizando a base de dados Best Artists Dataset – Grammys & Billboard (kaggle.com in Bing), especificamente o arquivo Money Makers BB.

🔧 Etapas realizadas
Importação da base de dados no SGBD escolhido.

Criação da tabela e inserção dos registros.

Execução de consultas SQL para responder às questões propostas.

📌 Consultas realizadas
Quantidade de artistas, registros e colunas da base.
Artista com maior número de visualizações totais.
Artista com menos visualizações em streaming.
Artista com mais visualizações em turnês.
